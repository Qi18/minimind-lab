# S01R1 SFT 评测摘要

## 验收结论

S01R1 可以作为一次完整实验收尾，但不能作为可发布的 SFT 模型验收通过：训练数值验收通过，官方七项知识能力没有回退；固定 Chat 和 Tool 行为验收未通过。

- best validation loss 为 1.702404，相比 P01 step-0 的 2.469205 下降 31.06%；final 与 best 相同，没有后期回退。
- 官方七项宏平均为 32.04，比 P01 的 31.44 高 0.60 个百分点，比 README 中官方 minimind-3 64M 的 30.78 高 1.26 个百分点。
- Chat 自动通过率只有 10.0%，6 个格式约束用例 0 个通过，10 个样例中 8 个出现明显重复。
- Tool 选择正确率 50.0%，端到端成功率 37.5%（3/8）。

因此本实验的准确表述是：SFT loss 收敛且通用选择题能力未退化，但对话指令遵循、格式控制和稳定生成仍不合格。

## 官方七项对比

主指标固定为任务提供 `acc_norm` 时使用 `acc_norm`，否则使用 `acc`。S01R1 为 0-shot、启用 chat template；P01 是 Base checkpoint，不启用 chat template。

官方 README 没有冻结 harness commit、dataset revision 和完整环境，因此不能声称严格复现或正式超过官方。P01 与 S01R1 的模板处理也按模型类型不同，表中的自身对比用于能力回归观察，不是单变量因果结论。

## 行为样例诊断

- `17 + 25` 被回答为 35，并重复展开错误步骤。
- 精确 JSON、三行列表、只回复 `READY` 等约束均失败。
- `translate_text` 能选择工具，但最终仍输出中文；时间工具有无效参数或错误标签。
- 成功样例包括 Python `add` 函数，以及计算、单位换算、天气三个工具链路。

原始 18 条输出均保存在 `samples.jsonl`，不能用挑选后的好样例替代整体通过率。

## 系统指标

- 设备：单张 NVIDIA L20，FP16，greedy；5 次预热、20 次测量。
- 首 token 延迟：中位数 3.86 ms，P95 3.93 ms。
- 64-token 总延迟：中位数 235.98 ms，P95 239.67 ms。
- 解码吞吐：中位数 271.21 token/s。
- 峰值 allocated / reserved 显存：131.69 / 170.00 MiB。
